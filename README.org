#+title: dotfiles

Dotfiles managed with Stow for Brew, Apt or Dnf

* Brew

** Prerequisite

Homebrew

#+begin_src sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
#+end_src

** Installation

Install Stow

#+begin_src sh
brew install stow
#+end_src

Setup dotfiles

#+begin_src sh
stow bat brew bin git zsh
#+end_src

Install packages

#+begin_src sh
brew bundle -v --file ~/.config/brew/Brewfile
#+end_src

** Declarative Brew packages

#+begin_src sh
# create a copy of the sample packages file
cp ~/.config/brew/packages.sample.rb ~/.config/brew/packages.rb

# edit packages file to add extra packages
emacs ~/.config/brew/packages.rb

# run the `brew-switch` alias
brew-switch
#+end_src

* Apt (Ubuntu/Debian)

** Prerequisite

Ubuntu, Debian or any derivatives of either.

** Installation

Install Stow

#+begin_src sh
sudo apt install stow
#+end_src

Setup dotfiles

#+begin_src sh
stow apt bat bin git emacs zsh
#+end_src

Install packages

#+begin_src sh
bash ~/.config/my-apt/core.sh
#+end_src

** Additional Packages

#+begin_src sh
# create a copy of the sample packages file
cp ~/.config/my-apt/packages.sample.sh ~/.config/my-apt/packages.sh

# edit packages file to add extra packages
emacs ~/.config/my-apt/packages.sh

# run the `apt-switch` alias
apt-switch
#+end_src
