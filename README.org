#+title: dotfiles

Dotfiles managed with Stow for Brew, Apt or Dnf

* Brew

** Prerequisite

Homebrew

#+begin_src sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
#+end_src

** Installation

*** Install Stow

#+begin_src sh
brew install stow
#+end_src

*** Setup dotfiles

#+begin_src sh
stow bat brew bin emacs git zsh
#+end_src

*** Install packages

#+begin_src sh
brew bundle -v --file ~/.config/brew/Brewfile
#+end_src

** Declarative Brew packages
*** Create a copy of the samples file

#+begin_src 
cp ~/.config/brew/packages.sample.rb ~/.config/brew/packages.rb
#+end_src

*** Edit packages file to add extra packages

#+begin_src sh
emacs ~/.config/brew/packages.rb
#+end_src

*** Run the =brew-switch= alias

#+begin_src 
brew-switch
#+end_src

* Apt (Ubuntu/Debian)

** Prerequisite

Ubuntu, Debian or any derivatives of either.

** Installation

*** Install Stow

#+begin_src sh
sudo apt install stow
#+end_src

*** Setup dotfiles

#+begin_src sh
stow apt bat bin emacs git zsh
#+end_src

*** Install packages

#+begin_src sh
bash ~/.config/my-apt/core.sh
#+end_src

** Additional Packages

*** Create a copy of the sample packages file

#+begin_src 
cp ~/.config/my-apt/packages.sample.sh ~/.config/my-apt/packages.sh
#+end_src

*** Edit packages file

#+begin_src sh
emacs ~/.config/my-apt/packages.sh
#+end_src

*** Run the =apt-switch= alias

#+begin_src 
apt-switch
#+end_src
